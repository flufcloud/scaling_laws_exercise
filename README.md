# Scaling Laws Exercise

Worked solutions to Vlad Feinberg's scaling laws exercises:

https://vladfeinberg.com/2026/05/10/how-to-land-a-job-at-a-frontier-lab.html

This repository contains my original submissions and revised versions of the
exercise writeups. The revised reports incorporate feedback I received from
Vlad Feinberg.

## Contents

- `jaxbook_worked_exercises_original.pdf`: Original JAX book worked-exercise submission.
- `jaxbook_worked_exercises_revised.pdf.pdf`: Revised JAX book worked-exercise submission.
- `scaling_laws_original_report.pdf`: Original scaling laws report.
- `scaling_laws_revised_report.pdf`: Revised scaling laws report.
- `jaxbook_handwritten_solutions/`: Handwritten solutions for selected JAX book chapters.
- `lib/`: Code, notebooks, and experiment utilities used while working through the exercises.
- `notebooks/`: Additional notebooks related to the exercises.
- `recordings/`: Supporting recordings.

## Notes

The original reports are preserved for comparison. The revised versions are the
main polished outputs after iterating on feedback.
